# Reminders PWA Pro

An iPhone-first Progressive Web App. No Mac or Xcode required.

## Run it
A PWA must be served from HTTPS (or localhost). The simplest options are GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any HTTPS static host.

Open the hosted page in Safari on iPhone, tap Share → Add to Home Screen.

## Features
- iPhone-style UI
- Natural-language quick entry
- Today / Tomorrow / Upcoming / Completed
- Search
- Edit/delete/complete
- Notes and priority
- Repeating reminders
- Offline caching
- Local-only storage
- Notification permission when supported
- Home Screen installation

Important: browser/PWA notification behavior on iOS is controlled by iOS and is not identical to Apple's native Reminders. For the most reliable future notifications while the app is not open, a native iOS app or push-notification backend is required.
